# AIAU イベント告知投稿ジェネレーター

## 概要

AIAU（AIエージェントユーザー会 @ai_agent_ug）のX投稿スタイルに準拠したイベント告知文を生成する。

## 文体ガイドライン

### 基本トーン
- **敬体（です・ます調）** を基本とする
- フォーマル度: 公式告知 > リマインダー > カジュアル告知
- 感嘆符「！」を積極的に使用（熱意の表現）
- 絵文字は控えめに（🎉🔥⚡️🎊📅📍程度）

### ヘッダーパターン
全投稿は【】で囲んだヘッダーで始める:

| シナリオ | ヘッダー例 |
|---------|-----------|
| 初回告知 | 【開催決定！】【申込受付中！】【イベント開催のお知らせ】 |
| 追加告知 | 【緊急告知！】【増枠&CfP募集】【来日決定】 |
| リマインダー | 【開催間近！】【開催前日！】【開催直前】 |
| 当日 | （ヘッダーなし or【お知らせ】） |
| 開催後 | 【御礼】 |
| 中止/延期 | 【お知らせ】 |
| カジュアル | 【大阪開催】【ハッカソンやります⚡️】 |

### 語彙選択
- 公式: 「開催します」「開催いたします」「ご参加ください」
- ややカジュアル: 「やります！」「ぜひご登録ください！」
- カジュアル: 「やります！」「気軽に参加してね！」
- 感謝: 「ありがとうございました！」「よろしくお願いいたします！」

## 情報構造（投稿の骨格）

```
【ヘッダー】
{イベント名} + 一言アピール

{補足情報（ゲスト、特徴、注意事項）}

📅 {日付}({曜日}) {時間}~
📍 {会場名}

▼申込 / ▼詳細
{URL}
#{ハッシュタグ}
```

### 日時表記ルール
- 形式: `MM/DD(曜日) HH:MM~` または `M月D日(曜日) HH:MM`
- 例: `08/01(土) 16:00~`、`5月27日`、`07/08 19時~`

### URL配置
- 「▼申込」「▼詳細」「▼詳細・申込」のラベルを付ける
- URLは投稿末尾付近に配置
- ハッシュタグはURLの後

## ハッシュタグ規則

### 基本方針
- ハッシュタグは**ユーザーが明示的に指定する**（自動生成しない）
- ユーザーからハッシュタグの指定がない場合は、投稿に含めず確認する

### 配置と数
- 基本1個、多くて2個
- 文末に配置（URLの後）
- スポンサータグを追加する場合あり（例: #さくらのAI）

| 3〜5週間前 | 初回告知（開催決定） | 11:00 or 20:00 |

## 使用手順

1. ユーザーからシナリオ種別と必要情報を取得（ハッシュタグは必須）
2. 該当テンプレートを選択（[references/templates.md](references/templates.md) 参照）
3. 変数を埋めて投稿文を生成
4. **文字数チェック**（下記参照）
5. メディア添付の推奨を提示
6. 投稿タイミングの提案を付記

## 文字数チェックフロー

X の投稿制限は **140文字**（日本語）。
生成後に以下の手順で必ず検証する。

### カウントルール
- URL は**実際の表示文字数**でカウント（固定ではない）
- ハッシュタグは「#」+ 文字数でカウント
- 絵文字は **2文字** としてカウント
- 改行は **1文字** としてカウント
- @メンションは @ + screen_name 文字数でカウント

### チェック手順
1. 生成した投稿文の文字数を上記ルールで算出する
2. 140文字以内 → そのまま出力
3. 140文字超過 → 以下の優先順位で削る:
   - a. 補足文・修飾語を削る（「ぜひ」「とても」等）
   - b. 空行を削る
   - c. 本文を要約する（意味を変えず短縮）
   - d. 日時・場所の表記を短縮（「2026/8/21 Fri 19:00~22:00」→「8/21(金) 19:00~」）
4. 削った後に再度カウントし、140文字以内であることを確認
5. 最終出力時に文字数を併記する（例: 「※ 128/140文字」）
